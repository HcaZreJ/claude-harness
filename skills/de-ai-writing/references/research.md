# AI 味写作调研存档

> SKILL.md（2.0）是工作层，本文是依据层：§〇 机制理论（二轮调研，2.0 的理论基础）+ §一~七 特征全表存档（一轮调研，现作为 `scripts/check.pl` 残渣检测的模式来源）+ 全部信源。

## 〇、机制理论（2026-07-23 二轮调研）

**定义**：AI 味文字有两类死法。
**第一类：句子没有内容（表演）**。句子的目的是让读者「觉得」（专业/亲切/深刻/有干货），而非让读者「知道」一件具体的事。下文四层特征表全部是表演的表层症状；症状可以互换（语域置换），机制不变。
**第二类：句子有内容，但编码失败**。写的人知道想说什么，但为省字数或表演口语感而生造压缩词（「提高团队的工作效率」压成「提效」；「列出你手上正在做的任务」说成「摊开你的日程」）、省略句子成分（「记在日历上」写成「记日历」），读者第一次读只能靠猜。2026-07-23 用户对两份长文案初稿的退回意见证实了这一类：修法全部是「换成常用说法、成分写全、并列项用完整句式逐项重复、接受句子变长」。对读者省力的重复不是冗余。

**三条推论**：
1. **语域无罪，所指定罪**。学术腔、营销号腔（「三招」「干货」「效果惊人」）、伪口语（「白搭」「踩坑」）都是预制语域。删负例不产生正例：禁掉一个语域，模型掉进下一个最高概率语域。判定只看所指——句子里有没有能指认的具体对象。
2. **具体性不可伪造**。语法、语气、节奏都可模仿；「只有做过这件事的人才写得出的细节」不可模仿。所以核查动作全部落在所指上（删句/所指/兑换/朗读四测试），不落在措辞上。
3. **材料先于句子**。没有具体材料，任何风格规则都只产出新预制件；写作卡壳 = 缺材料的信号，解法是回去要材料，永远轮不到「找一个更好的说法」。

**正面传统（二轮亲自调研的收敛点）**：
- **Orwell《Politics and the English Language》(1946)**：坏散文 = 短语「像预制鸡舍的板材一样拼装起来」（"phrases tacked together like the sections of a prefabricated hen-house"）；两类预制件：dying metaphors（用惯的现成比喻）、verbal false limbs（撑场面的动词假肢）。写作顺序：先问「我要说什么」，然后才选词。对 LLM 文风的机制描述早于 LLM 八十年。
- **Ted Chiang《Why A.I. Isn't Going to Make Art》(New Yorker, 2024)**：写作是「对几乎每一个词做选择」；生成模型替你填掉全部你没做的选择，填入的是语料平均值。
- **Paul Graham《How to Write Usefully》《Write Like You Talk》**：useful = importance × novelty × correctness × strength；「复杂句式与华丽词汇给写作者制造『说了很多』的错觉」；逐句测试「对朋友我会这么说吗」。
- **汪曾祺《中国文学的语言问题》**：「语言的美不在一个一个句子，而在句与句之间的关系」——直接否定金句思维：孤立句的漂亮是廉价的，质量在句间的信息递进里。
- **Klinkenborg《Several Short Sentences About Writing》**：received language——承袭来的语言会在不知不觉中替人写作，每个句子必须逐个经过注意（noticing）。

**六个已证实的封装失败模式（决定 SKILL.md 3.0 的形态）**：
1. **语域置换**：1.0 版的 ✓ 改写把顾问腔换成了营销号腔（「三招搞定」）和伪口语（「后面全白搭」）——衣服换了，表演没变。中文「去AI味」内容生态本身就用营销腔写作（展品：《3招秒去AI味！让文章像人写的》），从该生态取正例必然复制此病。
2. **few-shot 污染**：SKILL.md 里的 ✗→✓ 对照与范文会被执行模型表面搬运到不适用的场景。因此不含任何可模仿的成品句：核查以问题呈现，检测正则移入 `scripts/check.pl`（执行而不读入上下文）。
3. **名家语料的取舍**：零风格（平铺直叙 + 真实所指）不需要范本；名家段落常驻上下文 = 仿写与 pastiche 风险。某任务确需特定味道时，把人写的种子段落作为该次任务的输入材料，不进 skill 常驻层。
4. **配额 = 漏洞**（2026-07-23 长文案初稿实证）：规则写成「金句可以保留 ≤1」，执行模型就会把全篇最空的口号归类成金句保下来，并在自检报告里引用配额为自己豁免。修辞管理从配额制改为零默认制：默认为零，每处保留单独写理由，「配额没用完」「这是金句」都不是理由。
5. **✓ 表格自检 = 走过场**（2026-07-23 两份长文案初稿实证）：两份 v1 都附了全绿自检表，但「摊开你的日程」这种首读即挂的句子照样全过。原因有二：检查者是刚写完的同一个脑子，会替句子脑补意图；核查时看着设计说明（元描述里写了所指，句子本身没有传达）。对策：核查只对「读者实际会看到的纯文案清单」做（提取出来脱离设计说明），关键句手写测试答案，禁止打勾表。
6. **过度压缩即新表演**（同上实证）：往「短、口语」方向优化会催生生造压缩词与缺成分句——第二类死法。追加规则：用常用词、成分写全、并列项完整重复、宁长勿歧义；标题钩子只能来自最具体的事实或读者任务。规范文档自身同理：指令要用完整句子把动作说全，标题式压缩（「攒材料（任何句子之前）」）连人都读不懂，更不能指望执行模型读懂。

## 一、词汇层

### 1. "华丽废词"（学术腔升级词）
- **典型例子**：delve（深入探讨）、intricate（错综复杂）、tapestry（画卷/图景）、testament（明证）、underscore（凸显）、pivotal（关键性）、realm（领域）、navigate（把握/驾驭）、showcasing、compelling、paramount、meticulous、foster、elevate
- **中文对应**：赋能、抓手、闭环、底层逻辑、颗粒度、心智、势能、生态、体感
- **为什么读起来累/假**：arXiv 论文《Why Does ChatGPT "Delve" So Much?》统计出 21 个"焦点词"，指出它们在科学摘要中的激增速率明显是 LLM 使用导致，RLHF 很可能是助推因素之一。中文互联网黑话（抓手/赋能/闭环）同样是"拒绝好好说话，用一堆看似高级的行话表达简单意思"。这类词的共同特点：脱离具体语境也能安全使用，读者读到时得不到任何新信息，只感到被"镀金"。
- **改写策略**：把抽象升级词换成具体动词或数字。
  - "本文将帮你深入探讨远程协作的底层逻辑" → "三招搞定远程协作，效率翻倍"
  - "构建高效协作的闭环" → "让沟通少绕两次弯"

### 2. "借来的宏大"名词（tapestry 型）
- **典型例子**：tapestry、landscape、paradigm、ecosystem、mosaic、beacon、cornerstone、odyssey；中文对应"图景""版图""浪潮""赛道""新范式"
- **为什么读起来累/假**：把琐碎、具体的主题强行套上史诗叙事。Forbes 曾评论"我不再相信有人能无辜地在文章里用 tapestry 这个词——如果出现了，那就是 ChatGPT 写的"。中文对应病灶是"万物皆可'本质上'"：把具体判断偷换成空洞的哲学化陈述，建议替换为"说到底""其实"。
- **改写策略**："AI 正在重塑职场协作的版图" → "AI 让开会这件事变了"

### 3. "假客观"归因短语
- **典型例子**：英文 "Industry reports suggest / Observers argue / Studies show"；中文"有研究表明""不少专家指出""业内普遍认为"
- **为什么读起来累/假**：模糊归因、无具体来源，是典型的"虚假权威铺垫"。在短文案里纯粹是字数填充，读者无法验证也无法行动。
- **改写策略**：给出真实来源，或直接删掉，把判断句变成陈述句。"有研究表明，及时反馈能提升团队效率" → "反馈越快，团队跑得越快"

### 4. 副词/程度词滥用
- **典型例子**："quietly""deeply""remarkably""significantly"；中文"极其重要""必须""非常关键""十分严峻"
- **为什么读起来累/假**：堆砌程度词是自信心不足的信号——真正的重要性靠事实本身撑起来。
- **改写策略**：删掉程度副词，让名词和动词自己说话。"这一步非常关键，必须高度重视" → "这一步做不好，后面全白搭"

## 二、句式层

### 5. 否定-转折句（"不是 X，而是 Y"）—— 重点深挖

中英文 AI 味最一致公认的头号标志。

- **典型例子**："不是不努力，而是把力气用错了阶段"／"It's not just a tool, it's a partner"
- **来源确认**：英文侧多篇资料（popularai.org、blakestockton.com、hardlyworking1.substack.com、gist.github.com/ossa-ma 的 tropes 清单）都把 "not X, it's Y" 列为"单一最强 AI 写作信号"；中文侧虎嗅《"不是...而是..."刷屏的一年》与无尘阁日记的分析专门讨论此句式。

**为什么它是 AI 高频模式**：
- 信源指出的机制：逻辑学上叫"否定肯定式"，本意是强调重点、制造认知反差；大模型从海量语料统计选择最稳妥组合——这个句式在营销文案、鸡汤观点文里频率极高，被模型学成"安全牌"。
- **分析补充**：它是一种**零成本的深刻感生成器**——不需要真正论证 A 和 B 的因果关系，只需把 A 否定掉、把 B 摆出来，读者大脑自动脑补"反转"带来的顿悟快感，即便 A、B 未必互斥（常是伪对立）。对模型它是**万能语法模板**：任何话题套进"不是 X，而是 Y"都能生成通顺、听感"高级"的句子——模型不知道怎么深入论证时的"生成逃生舱"。出现一次尚可制造反差；三次以上读者模式识别触发，"深刻感"瞬间破功变"套路感"。
- **中文变体清单**："不是 A，是 B"／"不是不 A，而是 B"／"这不仅是 A，更是 B"／"不是因为 A，而是因为 B"／"表面看是 A，实际是 B"／"哪里是 A，分明是 B"。

**改写策略**：
1. **直接给结论，砍掉否定的前半句**——多数场景否定半句是废话。"不是不努力，而是把力气用错了阶段" → "力气用错了阶段"
2. **换成因果句且具体化**——把抽象的 A/B 换成可验证的具体行为或数字。"他不是不努力，而是方法不对" → "他这三个月天天加班，但优化的都是不该碰的模块"
3. **用画面/场景代替解释性对比**。"这不是效率问题，而是流程问题" → "同一份周报改了五遍，每一遍都卡在审批链上"
4. **全文最多保留一次**——确有强反差时可作全文压轴，而非开篇模板。

### 6. "不仅是 X，更是 Y" / 三段排比
- **典型例子**："这不仅是一次学习，更是一次成长"；"brilliant, brave, and bold"；中文"清晰、高效、可执行"
- **为什么读起来累/假**：Rule of Three 本是修辞传统，单次优雅；LLM 把它当默认模板反复套用——"单个三段排比是优雅的，连续三个三段排比就是模式识别故障"。中文侧"AI 是排比句狂魔"。
- **改写策略**：短文案最多一次排比，且三词各携带不同信息。"这套方法清晰、系统、可落地" → "这套方法，你今天就能用"

### 7. 空洞的插入语/过渡词
- **典型例子**："值得注意的是""不难发现""可以说""事实上"；英文 "It's worth noting""Importantly""Interestingly"
- **为什么读起来累/假**：不携带信息，只是宣告"接下来这句很重要"——重要与否应由内容体现。
- **改写策略**：直接删除，句子照样成立且更利落。

### 8. 过度 hedging（不敢下判断）
- **典型例子**："可能""或许""在某种程度上""从某种角度看"
- **为什么读起来累/假**：AI 因安全对齐倾向对一切持保留态度，语气均匀谨慎，缺乏人类写作的语气强弱变化（uniform cautiousness vs natural confidence variation）。hedging 词直接稀释行动指令力度。
- **改写策略**：敢下判断、给明确指令。"这可能在某种程度上帮到你" → "这招能帮你"

### 9. 自问自答式修辞
- **典型例子**："The result? Devastating."／"结果如何？出乎意料"
- **为什么读起来累/假**："The X? A Y." 模式是廉价悬念公式，用多了表演痕迹重。
- **改写策略**：直接陈述结果。

## 三、结构层

### 10. 挑战-展望的刻板收尾
- "尽管面临诸多挑战，但前景依然广阔"——Wikipedia《Signs of AI writing》列出的"stereotyped challenges-and-future-outlook conclusion"：不需要真正论证就能收尾的公式。改写：给具体的下一步行动，或干脆不写展望句。

### 11. 总-分-总/教科书式起承转合
- 中文信源列为 AI 味大特征——"逻辑过度规整""教科书式起承转合"，"永远正确的废话文学"；句长、段落节奏的单调重复也是结构层破绽。短文案里总分总把字数耗在自我复述上。改写：删"首先…其次…总之…"脚手架词，直接给内容。

### 12. Bullet / 列表滥用（"listicle in a trench coat"）
- 本该连贯叙述的内容被拆成条目——"穿着风衣的列表"：用列表伪装结构感，实际回避把句子间逻辑讲清楚。改写：能用一句因果句讲清的不拆列表；确需并列时控制条数且各条独立成立。

### 13. Fractal summaries（逐层自我总结）
- 每节开头"接下来我们要讲…"、结尾"以上就是…"——"signposted conclusion"在各层级反复出现，本质是自我重复。改写：删所有元话语，内容直接开始、直接结束。

### 14. 对仗式/口号式小标题
- "提升效率，赋能团队"——追求形式对称而非信息量，两短语常同义反复。（此条为分析归纳，与"三段排比"同源。）改写：小标题直接说人话。"提升效率，赋能团队" → "这一步，能省一半开会时间"

## 四、语气层

### 15. Em dash（破折号）成瘾
- 多篇英文信源一致指出这是最易被直觉识别的"AI 手感"之一；中文写作习惯里破折号本不常见，属翻译腔遗留。改写：优先句号断句；全文最多一次，用于真语义中断。

### 16. 表演式坦诚 / 假脆弱
- "这不是一篇软文，这是一次诊断"；"说实话，这个问题我也想了很久"——"false vulnerability"：模拟坦诚感的修辞姿态。真诚感来自具体细节（真实数字、真实场景）。

### 17. "让我们来分解一下"式说教腔
- "Let's break this down"／"我们来拆解一下"——自我授权的教学者姿态，占字数不传递信息。直接进入内容第一句。

### 18. 情感扁平、中立到没有棱角
- 全文无一句带个人色彩的判断——真正的人类表达有态度、有取舍；AI 输出要覆盖所有可能性，谁都不得罪、谁都打动不了。"过度完美"（语法结构零瑕疵）本身就是破绽。改写：敢站在读者一边说话，允许轻微不完美与口语语气。

### 19. 过度承接式开场
- "你说的很对，这个问题一针见血"——颁奖式开头、推销式结尾。删除客套开场，直接给信息。

## 五、反方向：好中文表达的原则

### 5.1 得到"说人话"传统
脱不花《沟通的方法》："用别人的视角去感知自己""说人话"。可执行判据：**任何一句文案，读完后对方能不能立刻说出"具体要做什么"——做不到就是没说人话。**

### 5.2 余光中《现代汉语的西化》——地道中文对照坐标

| 西化/翻译腔 | 地道中文 | 问题 |
|---|---|---|
| 他的收入的减少改变了他的生活方式 | 他因为收入减少而改变生活方式 | 名词化堆砌，"的"字连环 |
| 本校的校友对社会作出了重大的贡献 | 本校的校友对社会贡献很大 | 弱动词"作出"+抽象名词 |
| 有关文革的种种，令人不能置信 | 文革的种种，令人不能置信 | 介词"有关"赘余 |
| 这一项提案已经被执行委员会讨论 | 这一项提案执行委员会已经讨论 | 被动语态硬译自英文 |

核心：西化"化简为繁、以拙代巧"——与 AI 味的名词化、被动化、连接词冗余高度同构。

### 5.3 "说人话" skill 的实操框架（GitHub 项目 shuorenhua）
六步流程：① 判场景 ② 划保护片段（数字、专有名词、命令不能动）③ 判命中强度 ④ 按模式改写 ⑤ 保真回读（事实没被改动）⑥ 残味审计（改完再查漏网 AI 腔）。关键判据：**改写目标是"具体动作优先、真主语优先"，而非机械消灭词汇。**

### 5.4 宝玉的核心洞察：风格画像优于禁用清单
单纯给 AI 一份"禁止词清单"，所有人用同一套清单，产出又变成新的同质化（"AI 味 2.0"）；有效方式是给一份持续迭代的**写作风格画像**（角色定义+风格要点+禁止清单+参考例文）——"**你只能用你自己的味道盖过去，而不是消除 AI 味道本身**"。
**对 agent 的修正（2026-07-23）**：这条对人成立，对 agent 只对了一半——agent 没有自我味道可用，「表演一种味道」正是 AI 味本身。agent 唯一诚实的味道是材料的味道：零风格 + 真实所指（见 §〇）。

## 六、学术侧：LLM 输出的 stylometric 特征

1. 《Why Does ChatGPT "Delve" So Much?》（Juzek & Ward, COLING 2025）：21 个焦点词在科学摘要激增，归因 RLHF 而非训练数据/架构。
2. 句长分布：人类写作句长方差更大，LLM 集中在 10–30 token，均匀度显著高于人类；标准差本身是有效分类特征。
3. 组合特征（词汇多样性+词性频率+标点熵+困惑度+burstiness）F1=0.94，显著优于纯困惑度模型（F1=0.81）——支持"四层分类法"的合理性。
4. 《Contrasting Linguistic Patterns in Human and LLM-Generated News Text》（arXiv 2308.09067）：模型对"句法模板"的依赖显著高于人类——与否定-转折句、三段排比的成因一致：复用见过的句子骨架最省力。
5. 《Stylometry Recognizes Human and LLM-Generated Texts in Short Samples》：短样本中风格特征依然有效区分——**篇幅短不代表 AI 味不明显；超短文案的规则要执行得更严，而非更松。**

## 七、英文骨架残留（翻译腔）

第三类死法的调研存档：句子的词是中文的，结构是英文的。SKILL.md 规则 4 的八条轴与第三步第六问「回译」由本节支撑。

### 7.1 判定法：回译对齐度

「读起来别扭吗」这一问在自查里失效——写出这句话的上下文正是因为觉得它不别扭才写出来的，判定者与生成者是同一个上下文。可执行的替代判定是数结构对应：把中文回译成英文写出来，数中文的每个成分在英文里是不是都有一个直接对应的词、位置也对得上。

地道中文回译成英文一定要挪动结构：两个中文小句合成一个英文句子，中文的动词换成英文的名词，中文的话题句要给英文补主语。逐词都对得上，说明这句话的结构是从英文来的。

同一件事的两种写法对照：

| 中文 | 回译 | 成分对应 |
|---|---|---|
| 链接也不会打断正文 | links won't interrupt the body either | 「也不会」对应 won't…either，拆到句子两头，发生位移 |
| 正文也不被链接打断 | the body is not interrupted by links | 正文=the body、也不被=is not、打断=interrupted、链接=by links，五个成分逐一贴合，无位移 |

这个判定不依赖语感，答案（英文回译）写得出来、可供核对。

### 7.2 中英句法差异八条轴

英文靠名词、从句、被动和形式主语把成分压进一个主句；中文靠动词和小句按顺序铺开。八条轴按这一差异的着力点排列，每轴给一到三组示例，示例句按轴给满。

| 轴 | 英文怎么组织 | 中文怎么组织 | 实证原句 → 改写 |
|---|---|---|---|
| 1 动作用动词写 | 动作装进名词（the certainty of portability、existence of complementarities、conduct approval of X） | 用动词把动作说出来 | 降低了跨平台可移植性的确定性 → 跨平台还能不能移植，变得更不确定；互补性的存在 → 是否存在互补性；对提交内容进行校验 → 校验提交内容 |
| 2 主语给能发出动作的人或事物 | 抽象概念可以当主语（This makes it harder、This lets X become Y、familiarity predicts ability） | 主语是能发出这个动作的东西 | 这使得把 agent 变成标准化搭档难得多 → 所以要把 agent 变成标准化搭档，比…难得多；这让「一人多角色」成为一等公民 → 「一人多角色」是系统原生支持的用法；响应时间显著预测其留存率 → 响应时间与留存率显著相关 |
| 3 条件、前提、状语写成前一个小句 | 介词短语与从句把条件压进主句（with X held constant、in the case where、across the channels、in the average） | 按时间或因果顺序分成小句 | 在配置不变的情况下把命中率移动 10–20 个百分点 → 配置不换，命中率也能移动 10–20 个百分点；跨开发、测试、预发、生产四个环境 → 在开发、测试、预发、生产四个环境上分别设置；在平均里抵消掉 → 在取平均时相互抵消 |
| 4 说出谁做了什么 | 无施事被动（is not interrupted by、is considered to be、is required to、is prohibited from） | 用主动说出施事；受事当话题时提到句首直接接谓语 | 正文也不被链接打断 → 链接也不会打断正文；调用方被要求做什么 → 调用方要做什么；订单表被明确禁止持有金额字段 → 订单表里不放金额字段 |
| 5 每换一次施事就写一次主语 | 一个主语挂一串动词，一主动一被动也合法（can override or be locked by） | 每个施事各自带一个主语 | 子配置可在允许范围内覆盖或被上层锁定 → 子配置可以在允许范围内覆盖上层配置，也可以被上层锁定 |
| 6 虚词和代词按中文的用法，能省就省 | 衔接词、强调词、指示词都要在句子里出现（this means、noteworthy、did、those、them、this fact） | 靠语序和上下文接住，不逐个对译 | 这意味着重心应该落在写入路径 → 所以重心应该放在写入路径；一个值得注意的内部不一致 → 一处内部说法不一致；确实招募了真人的研究 → 已经有一些研究招募了真人；记录「发生了一次导出」这一事实 → 记录发生过一次导出 |
| 7 比喻、搭配、术语用中文里现成的 | 习语与复合词按语素成立（low-hanging fruit、lazy-create、zero hits、floor、first-class citizen、happy path、pipeline、reach significance） | 用中文里这件事的现成说法 | 懒创建 → 按需创建；零命中 → 搜不到；地板线 → 基准线；一等公民 → 原生支持；快乐路径 → 正常流程；管线 → 流程；达到显著 → 显著；界定受众 → 说明给谁看；把机会做到最大 → 抓住机会 |
| 8 并列项用顿号，连接词只在最后用一次 | 三项以上并列每两项之间都放一个 and | 顿号分开，最后一项前用一次「和」或「与」 | 订单与库存与对账 → 订单、库存、对账；JSON 与 YAML 与 TOML 与 XML 与 CSV → JSON、YAML、TOML、XML 与 CSV；从取数到清洗到入库到校验 → 取数、清洗、入库、校验 |

余光中《现代汉语的西化》的四条对照（见 §5.2）分别落在轴 1（名词化堆砌、弱动词加抽象名词）、轴 3（介词赘余）、轴 4（被动硬译）。

### 7.3 正则的边界

翻译腔的判定几乎全靠上下文：同一个词在一个语境是病、在另一个语境正常。在 34031 句真实语料上逐条校准候选模式，结果决定了 check.pl 收哪些、放哪些。

| 候选模式 | 命中 | 判定 |
|---|---:|---|
| 使得 / 使之 / 令其 | 6 | 收：命中全为真病 |
| 在……的情况下 / 前提下 | 35 | 收 |
| 这意味着 | 16 | 收 |
| 这一事实 / 这一发现 | 7 | 收，排除「这一点」（「懂行的人会一眼看到这一点」正常） |
| X 的存在 + 说明/表明/证明 | 9 | 收，不带后接谓语时「真的存在」「确实存在」会误伤 |
| 被认为是 / 可以被理解为 | 6 | 收 |
| 被要求 / 被禁止 / 被期望 | 10 | 收 |
| 三个「与」串联 | 1 | 收，排除斜杠、括号、序号、引号后零误伤 |
| 名词化堆叠「X 性的 Y 性」 | 14 | 收，标注逐句确认，误伤约六成 |
| 进行 + 动名词 | 25 | 放：多数命中是「进行中 / 进行时 / 进行到一半」，正常中文 |
| 动词 + 它们 | 39 | 放：有明确复数先行词时「把它们收拢成一条」「让它们一条查询就能拿到」正常 |
| 「的」字连环（余光中判据） | 2 | 放：中文技术写作里召回率过低，两条命中全是误伤 |
| 两个「与」串联 | 32 | 放：「导入与导出的校验与回滚」是两组各自并列 |
| 地板线（floor 直译） | 68 | 放：在语料里已是固定用法，逐次报会盖掉真命中 |
| 允许你 / 使你能够 | 0 | 收：零误伤，形态公认 |
| 好问题 / 以下是（对话套语） | 17 | 收：零误伤，集中在汇报正文的开场 |
| 这就是为什么 | 2 | 收 |
| 数字直接接可数名词（6000 用户 / 100 请求） | 17 | 收：中间有量词时不命中，零误伤 |
| 被动连缀（一句两个以上「被 X」） | 0 | 放：语料里只有一条实例，靠轴 4 的文字描述人工过 |

| 对 X 进行 Y | 0 | 收：零误伤 |
| 对人类可读（形容词化） | 1 | 收：零误伤 |

正则筛词汇层的标记，结构层的病靠 §7.1 的回译对齐度与 §7.2 的八条轴逐句过。

### 7.4 语料与采集口径

来源：`~/.claude/projects/` 下 2026-08-17 之后修改的 346 个会话记录（381MB），提取 assistant 回复正文与 Write/Edit 写入的文档内容，过滤出中文占比 45% 以上、长度 10–130 字的句子，得 34031 句。

采集观察：走完 de-ai-writing 流程的定稿里翻译腔密度显著低于草稿；语料里样本密集的位置是**评审记录**——独立复审 sub-agent 把草稿的原句整句引用进报告，那些被引用的原句是真实成品句。这说明流程在被调用的地方有效，密度高的位置是没走流程的输出：草稿、中间产物、以及在对话里直接给用户的汇报正文。

SKILL.md 自查一遍的结果（v3.6.0 自身文本）：命中 20 处，分布在轴 1（完整表达、出现频率极高、两种处理方式、缺陷汇总）、轴 2（句式承载着结构、生成惯性不会消失）、轴 3（在毫无准备的情况下）、轴 4（正文也不被链接打断、对人类可读）、轴 6（读到它们的、无法从它知道、与此一致、流程不会）。当时的自查规则一条都没抓住这 20 处，因为那一版的直译测试只给了语序类例子，执行者按语序去查，名词化、抽象主语、被动、代词回指全部漏过。示例窄化检查面这一点，在规则里给例子时要按轴给满。
三批采集各自的负面发现，同样是判定依据：

- 英文习语直译（低垂的果实、房间里的大象、把 X 摆到桌面上、移动指针、在一天结束时、第一公民、把球踢给）在 21635 行候选文本里逐一检索**零命中**。这批语料不是没有隐喻，是隐喻不取自英文习语库，而是就着当下的事自造的具体类比。轴 7 因此把术语按语素拆译放在前面，英文习语列在后面。
- 「作为一个……的人」开头、状语错位（他都试一个、你团队三个月后）在第三批语料里零命中。
- 连接词密度过高（然而 / 此外 / 另一方面 连用）零命中：「然而」0 处、「另一方面」0 处、「此外」5 处且都单独出现。
- 从句照搬在这批语料里零命中，草稿的从句普遍较短、没有多层嵌套。

段落结构层的一个观察（不属于句子层的八条轴，留在此处备查）：调研类输出里反复出现「①②③④ 编号 + 加粗术语 + 冒号引出解释」这套骨架，来源是英文学术论文的结构化摘要（Background / Methods / Results / Implications）与咨询报告模板。它在文献综述类 sub-agent 报告里是贯穿全部产出的固定写法，不是偶发。中文的分析性写作让论点在连贯段落里出现，不必给每一层意思标号定式。
